# Cliff Joseph C. Ligaya — Portfolio

Responsive personal portfolio built with HTML, CSS, and JavaScript. Includes six Alpine Summit LIA social campaign samples.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `cliff-joseph-ligaya`.
2. Upload the contents of this folder to the repository's `main` branch.
3. In repository **Settings → Pages**, choose **GitHub Actions** as the build and deployment source.
4. The workflow in `.github/workflows/pages.yml` will publish the site. GitHub will show the public URL in the Pages settings and deployment run.

The portfolio contains contact information intended for public professional inquiries. Review it before publishing.
